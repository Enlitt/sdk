# Contributing

This repository is a read-only mirror of the packages Enlitt develops in its private repository,
so pull requests here cannot be merged and are closed automatically.

Your feedback is still very welcome:

- **Bug or unexpected behavior:** open an issue with the package and version, what you ran, and
  what happened. A minimal reproduction helps the most.
- **Feature request or question:** open an issue describing what you are trying to build.
- **Security problem:** follow [SECURITY.md](SECURITY.md) instead of opening an issue.

If an issue includes a suggested fix, we will apply it upstream and it will appear here with the
next release.
